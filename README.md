## GitHub学習メモ

- git add：変更内容をステージングエリアに登録し、次のコミットに含める準備をします。
- git commit：ステージした変更をコミットとして記録します。
- git push：ローカルのコミットをリモートリポジトリに送ります。
- Pull Requests：ブランチ間の変更を提案し、レビューやマージを依頼します。

## Codexの学習

Codexは、コードを読んだり書き換えたりして、ソフトウェア開発を手伝うAIアシスタントです。たとえば、依頼に合わせてファイルを編集したり、変更内容を説明したりできます。作業内容を確認しながら使うことで、開発の進め方を学べます。

## GitHub Issueとは

GitHub Issueは、リポジトリで対応したい作業や、見つかった問題を記録する機能です。Issueにはタイトルや説明を書き、コメントで相談したり、ラベルを付けて内容を整理したりできます。作業が完了したら、Issueを閉じて対応済みであることを示します。
